  • Open Genre and check the ones you want. Several at once mean all of them. A tag on a row does the same check.
  • The + on a row adds or removes that sample's tags. A rescan keeps those edits.
  • Search matches words in the name, folder, or pack, in any order.
  • Space plays and pauses. Up and down move through the list. / focuses search.
  • To key changes pitch only. A relative key already fits, so an A minor loop in C major does not move. An open Ableton set also matches loop tempo.
  • Drag a row into Ableton. The file stays where it is. Right-click a row to open it in Explorer, or to copy the pitched and tempo-matched wav.
  • The link mark turns green when the plugin is connected. While it is on, a drag passes the original file. Repeat retriggers a one-shot on the grid.
  • BPM and key are read from the filename.
