  • Click a genre twice to exclude it. Kick, then Dubstep again, leaves dubstep out. A third click clears it. Several tags at once mean all of them.
  • Search matches words in the name, folder, or pack, in any order.
  • Space plays and pauses. Up and down move through the list. / focuses search.
  • To key changes pitch only. A relative key already fits, so an A minor loop in C major does not move. An open Ableton set also matches loop tempo.
  • Drag a row into Ableton. The file stays where it is. Right-click a row to open it in Explorer.
  • BPM and key are read from the filename.
